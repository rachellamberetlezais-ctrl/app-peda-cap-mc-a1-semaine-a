## Aides pour tous
Chaque activité et positionnement propose une barre Outils d’aide : agrandissement, espacement, méthode générale, glossaire scientifique écrit. Aucun classement ni étiquette personnelle, pas de LSF automatique. Les contenus pédagogiques des applications sont conservés ; seules une feuille de styles et un script d’aide ont été ajoutés.
Les noms éventuellement saisis dans les exercices d’origine ne sont pas envoyés par le portail. Les fonctions propres aux exercices restent celles du fichier fourni.

## Ajouter une application
Déposer son dossier complet dans applications/CODE/index.html, puis ajouter une entrée dans applications.js. Champs : code, annee, semaine, discipline (M ou P), activite, titre, description, lien. publication facultative au format ISO avec +04:00.

## Publication
Créer un dépôt public indépendant, ajouter ces fichiers à sa racine, activer Settings > Pages > Deploy from a branch > main > / (root).
Aucun autre dépôt n’a été modifié.
